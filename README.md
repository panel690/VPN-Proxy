VPNとプロキシ
VPNは通信全体を暗号化して、接続元のIPアドレスを隠します。プロキシは特定のアプリやブラウザーの通信を別のサーバー経由にしますが、通常は通信全体を暗号化しません。どちらも接続先から見えるIPアドレスを変えられます。
